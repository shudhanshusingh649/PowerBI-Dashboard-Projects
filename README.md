# 🌦️ ISRO Climate Prediction API

This project predicts:
- 🌧️ Rainfall
- 🌡️ Maximum Temperature
- ❄️ Minimum Temperature

using Machine Learning models and FastAPI.

## 📂 Dataset

Due to GitHub's file size limit, `climate_data_engineered.csv` is not included in this repository.

### Download Dataset

https://drive.google.com/file/d/1uk6iztJ0FlPWQUGUUBOLuAc39yQ7bHHv/view?usp=drive_link

After downloading, place the file here:

```
Final_Dataset/climate_data_engineered.csv
```

## ▶️ Run FastAPI

```bash
cd Fast_Api
uvicorn main:app --reload
```
