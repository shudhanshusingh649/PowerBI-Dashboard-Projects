# 🛒 E-Commerce Sales Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard developed using Microsoft Power BI** to analyze sales, profit, quantity, customer performance, payment methods, product categories, and regional sales performance.

The dashboard provides a business-focused view of e-commerce performance through interactive visuals, KPIs, and filters.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization
* Interactive Slicers

## 📊 Key Performance Indicators (KPIs)

The dashboard displays the following key metrics:

* **Total Amount:** 438K
* **Total Profit:** 37K
* **Total Quantity:** 6K
* **Total AOV:** 121K

> KPI values may change when filters are applied.

## 📈 Dashboard Visualizations

### 1. Highest Amount by State

Displays the states generating the highest sales amount.

The dashboard highlights the top-performing states, including:

* Maharashtra
* Madhya Pradesh
* Uttar Pradesh
* Delhi
* Rajasthan

### 2. Top 5 Customers by Amount

Shows the top five customers based on their total purchase amount.

### 3. Quantity by Payment Mode

Shows the distribution of order quantity across different payment methods:

* COD
* UPI
* Debit Card
* Credit Card
* EMI

### 4. Profit by Month

Displays monthly profit performance and helps identify months with higher and lower profitability.

### 5. Profit by Sub-Category

Shows profit generated by different product sub-categories, including:

* Printers
* Bookcases
* Saree
* Accessories
* Tables

### 6. Quantity by Category

Shows the distribution of quantity across major product categories:

* Clothing
* Electronics
* Furniture

## 🎛️ Interactive Filters

The dashboard includes an interactive **Quarter filter** that allows users to analyze performance across:

* Qtr 1
* Qtr 2
* Qtr 3
* Qtr 4

Users can also use the **All** option to view the overall performance.

## 💡 Business Insights

This dashboard can help businesses:

* Identify the highest-performing states.
* Analyze customer purchasing behavior.
* Understand preferred payment methods.
* Track monthly profit trends.
* Identify the most profitable product sub-categories.
* Analyze product category demand.
* Compare business performance across different quarters.
* Support data-driven sales and marketing decisions.

## 🎯 Project Objective

The objective of this project is to demonstrate practical skills in **Power BI dashboard development, data analysis, DAX, data modeling, KPI creation, and business intelligence visualization**.

The dashboard transforms e-commerce sales data into meaningful visual insights that can support business decision-making.
